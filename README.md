## Poznámka ke stavům

Rozcestník záměrně zachovává odkazy na starší i pracovní verze. Samotné uvedení v katalogu není potvrzením funkčnosti. Notebooky nebyly automaticky spuštěny a jednotlivé nástroje je třeba ověřovat přímo. Historické soubory zůstávají dostupné pro porovnávání a dohledání vývoje.

Zdrojová data zůstávají oddělená od odvozených analýz a experimentů.
